Général

Général

Les fonctions générales sont celles que vous pouvez utiliser sans aucuns préfix

printMessage

void printMessage(string message)
  • Ecris un message dans la console du bot.
Nom Description
message le message à afficher, de type string

Exemple:

printMessage("Mon super message") -- Mon super message

printDebug

void printDebug(string message)
  • Ecris un message en mode debug dans la console du bot.
Nom Description
message le message à afficher, de type string

Exemple:

printDebug("Message de debug") -- Message de debug

printError

void printError(string message)
  • Ecris un message en mode erreur dans la console du bot.
Nom Description
message le message à afficher, de type string

Exemple:

printError("Erreur fatale :(") -- Erreur fatale :(

printSuccess

void printSuccess(string message)
  • Ecris un message en mode succés dans la console du bot.
Nom Description
message le message à afficher, de type string

Exemple:

printSuccess("Youhouuuu!") -- Youhouuuu!

isInDialog

bool isInDialog()
  • Indique si votre personnage est en dialogue

Exemple:

if isInDialog() then
    printMessage("Je suis en dialogue") -- Je suis en dialogue
else
    printMessage("Je ne suis pas en dialogue") -- Je ne suis pas en dialogue
end

leaveDialog

void leaveDialog()
  • Quitte le dialogue

Exemple:

leaveDialog()

isFighting

bool isFighting()
  • Indique si votre personnage est en combat

Exemple:

if isFighting() then
    printMessage("Je suis en combat") -- Je suis en combat
else
    printMessage("Je ne suis pas en combat") -- Je ne suis pas en combat
end

isSubscribed

bool isSubscribed()
  • Indique si votre personnage est abonné à Dofus Touch

Exemple:

if isSubscribed() then
    printMessage("Je suis abonné") -- Je suis abonné
else
    printMessage("Je ne suis pas abonné") -- Je ne suis pas abonné
end

isGathering

bool isGathering()
  • Indique si votre personnage est en train de récolter

Exemple:

if isGathering() then
    printMessage("Je suis en train de récolter") -- Je suis en train de récolter
else
    printMessage("Je ne suis pas en train de récolter") -- Je ne suis pas en train de récolter
end

hasReachFightLimit

bool hasReachFightLimit()
  • Indique si votre personnage à atteint la limite des 800 combats quotidien
  • Attention: le mot "hasReachFightLimit" ne doit être en aucun cas inscrit dans le fichier du script en commentaire.
    Ce texte doit forcément être utilisé !

Exemple:

if (hasReachFightLimit() == true) then
    printMessage(J'ai atteint la limite des 800 combats ) -- J'indique que j'ai atteint ce seuil
    printMessage(Je peux par exemple aller à la banque désormais) -- Je peux traiter une fonction...
end

stopScript

void stopScript()
  • Arrête le script

Exemple:

stopScript()

delay

void delay(int quantité)
  • Met en pause le script pour un temps défini en millisecondes
Nom Description
quantité nombre de millisecondes, de type int

Exemple:

delay(5000) -- Je met une pause de 5 secondes

getTimeStamp

int getTimeStamp()
  • Renvoie sous forme de nombre le timestamp

Exemple:

timestamp = getTimeStamp() -- Ma variable timestamp stocke la valeur du timestamp

mapTeleport

void mapTeleport()
  • Permet d'éviter l'arrêt du script avant une téléportation de PNJ

Exemple:

npc.npc(-1,1)
if isInDialog() then
	delay(1000)
	npc.reply(-1)
	delay(1000)
	leaveDialog()	
	mapTeleport() 
end
-- En plaçant cette fonction dans ma fonction j'évite le bug
-- de l'arrêt du script suite à une téléporation de PNJ

bypassTuto

void bypassTuto()
  • Lorsque elle est appelée, permet de lancer le SKIP du tutoriel
  • Elle est utilisé suite à la création d'un compte (pas pendant le tutoriel si déjà lancée)

Exemple:

function bypass()
    bypassTuto()
end
-- Ensuite dans ma fonction move je rajoute la référence à la fonction custom bypass
{ map = "81002496", custom = bypass },  --Map du tutoriel / Bypass 
{ map = "81264644", changeMap = "bottom(559)" },  Après le tutoriel, on descend de map etc...

getSubscriptionPrice

int getSubscriptionPrice()
  • Permet de récupérer le prix de l'abonnement

Exemple:

function getPrix()
    getSubscriptionPrice()
end

subscribe

void subscribe()
  • Permet d'acheter l'abonnement si vous avez assez de kamas

Exemple:

function abonnement()
if isSubscribed() == false then
    price = getSubscriptionPrice()
    printMessage("J'ai ".. character.kamas() .. " kamas et l'abonnement coûte " .. price .. " kamas.")
    if character.kamas() > price then
        printMessage("J'ai assez d'argent et je ne suis pas abonné donc je vais m'abonner.")
        subscribe() -- Abonne le personnage si possible, renvoie en log les étapes...
    else
        printMessage("Je n'ai pas assez d'argent... tant pis.")
    end
end
